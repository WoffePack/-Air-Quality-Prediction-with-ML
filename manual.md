# Air Quality Monitoring (AQM) Project Manual

This manual will guide you through the basic steps to use the Air Quality Monitoring (AQM) project. Follow these instructions to set up, train, and utilize the model effectively.

---

## Requirements Installation

1. Ensure you have Python installed on your system.
2. Install the required dependencies by running the following command in your terminal or command prompt:

   ```bash
   pip install -r requirements.txt
   ```

---

## Model Training

1. Open the `main.ipynb` notebook in your Jupyter Notebook or compatible environment.
2. Follow the steps provided in the notebook to train the model.

   - Ensure you have the appropriate training dataset ready before starting the process.

3. Save the trained model upon successful completion of training.

---

## Loading the Model

1. Open the `model_loader.ipynb` notebook in your Jupyter Notebook or compatible environment.
2. Load the trained model using the instructions provided in the notebook.

   - Ensure the trained model file is in the correct location as specified in the notebook.

---

## Predicting with New Data

1. Prepare the data you want to predict.
2. Assign the data to the `data` variable within the `model_loader.ipynb` notebook.
3. Run the necessary cells to generate predictions.

---

## Notes

- Always ensure your dataset is in the correct format expected by the model.
- Refer to the comments in each notebook for detailed guidance.
- Keep the project directory structure intact to avoid path-related issues.
